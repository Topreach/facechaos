# Mobile screen prototype

Open `index.html` in a browser. No installation, internet connection, camera or
microphone permission is required. The camera image is an illustration.

The initial view is now a clean illustrated selfie camera. Open **Games** in
the phone to choose a game; Emoji Gates starts the simulated overlay. Other
game cards show the planned face/sound collection and remain Coming soon.
Close the game to return to the clean camera.

Explore Games, Camera setup, Gameplay, Results and Camera settings using the
buttons above the phone. Choose Play, then Continue. Press **Simulate a match**
six times to complete the sample course. Pause, hide/show, quality, mirroring
and reduced-motion controls demonstrate proposed interactions only.

This is a screen/navigation prototype, not implemented game logic, recognition,
a camera quality demonstration or an Android/iOS build. The Expression Escape
selection shares the sample interaction; its courses remain in the desktop
prototype. Next course restarts the sample rather than implementing unlocks.

The full scope, recognition limitations, privacy model, camera architecture and
real-device acceptance criteria are in [the mobile design](../docs/MOBILE_APP_DESIGN.md).

The Gameplay screen now uses an edge-to-edge illustrated selfie with transparent
game overlays. REC starts a simulated timer; STOP opens recording review. Save
and Share are demonstrations only and create no files or external actions.
