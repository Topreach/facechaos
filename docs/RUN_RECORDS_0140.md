# Fresh runs and per-game best coins - 0.14.0

Each game starts at Stage 1. Winning advances to the next stage with the same accumulated run coins. After a failure, the Mission failed screen shows the final run coins and saved best. Pressing the circle / Try again starts Stage 1 with fresh hearts, countdown, score and zero run coins. Restart, stopping/replaying, and completing all five stages also start a fresh run. The stage menu describes the journey without allowing stage skipping; legacy unlock data is retained but no longer used to resume or skip stages.

Each of the 15 games has its own best_run_coins preference. A strictly higher run coin total replaces it; lower totals and ties leave it unchanged. The record is updated as coins are earned, so earned progress can establish a record even if a run is later interrupted. It is separate from the existing lifetime coin balance and score-based records, which are retained. Current run and best appear in the HUD, result screen and game brief. Existing score records cannot reliably be converted into historical single-run coin totals, so the new coin records begin from this update.

Emoji Gates now awards one coin for each passed matched gate; Bubble Garden awards one coin per successful plant/bloom action. These two games previously lacked coin awards. Other coin rewards are unchanged.

Validation: pure checks covered all 75 game/stage restart/advance/carry decisions and all 75 winning paths, including positive coin rewards in every game. Existing 15-game winning/losing playthroughs passed. Build and Android lint passed. Native checks verified 15 independent persistent records, lower/tied/higher comparisons, reloading preferences, fresh Stage 1 retries and carried totals. Checks used a separate temporary preference file and synthetic states; player records were preserved. Four native result layouts rendered and Emoji Gates result was visually reviewed. Installed versionCode 32 / 0.14.0-runs on Samsung SM-A176B.
