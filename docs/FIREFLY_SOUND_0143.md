# Firefly Glow - sound-controlled flight, 0.14.3

The character is a firefly. The objective is to guide it to six lanterns: a gentle hum within the highlighted gold sound range moves it along a curved flight path toward the current lantern. Quiet or out-of-range sound makes it drift back. Reaching a lantern lights it and earns one coin. Each visited lantern is tracked independently, so a missed lantern is not falsely lit when a later one succeeds. Later stages retain faster cue timing, narrower sound ranges and higher accuracy targets. Existing Stage 1 retries and per-game coin records remain unchanged.

Firefly Glow now requires its phone microphone. It does not inherit the shared optional-sound preference, and no switch or touch gesture can turn its gameplay into touch control. Start, pause and recording buttons still work normally. Microphone calibration freezes the game clock. Missing permission or microphone failure pauses the game with permission/retry/other-game options, never a silent touch fallback. Briefing, catalog, accessibility description and live cues describe sound-controlled flight and contain no touch-to-light instructions.

Corrected the Firefly sound meter to use the sound gate's wider relative-strength measurement. The previous gate-display level saturated for many ordinary active sounds, putting them above the permitted target despite comfortable volume. The shared live-input adapter now supplies Firefly's meter and rules with the same relative strength; other games retain their existing level mappings. This does not promise accurate control for every room or microphone; users should calibrate quietly, then hum comfortably inside gold.

Validation: five complete synthetic-PCM-driven six-lantern stage wins; visible movement, quiet drift, out-of-range rejection, calibration freeze, touch rejection and unique coin checks passed. All 75 campaign winning paths and existing winning/losing game checks passed, as did stage-speed and sound-race regression checks. All 70 touch-compatible stages passed; Firefly's five stages are deliberately sound-only. Native tests verified required microphone settings and rendered 20 calibration/flight/arrival/reward scenes without opening a microphone. Flight scene visually reviewed. Offline build and Android lint passed. Installed versionCode 35 / 0.14.3-firefly on Samsung SM-A176B. Real voice response still needs the player's live test.
