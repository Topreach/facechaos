# Animal Choir - rhythm matching, 0.15.1

The player chose rhythm matching: dog = two short woofs, cat = one longer meow, bird = three short chirps. This is not animal identity classification. Correct complete patterns award one coin, then advance to the next animal. Six cues form a stage; later stages have faster cue timing and stricter stage targets. Existing Stage 1 failure retries and per-game best coins remain unchanged.

Animal Choir now uses its own animal_choir_microphone preference, enabled by default instead of inheriting the shared optional microphone setting. Explicit touch rhythm practice remains available and is visibly labelled. Microphone calibration freezes the round and countdown. Permission problems or microphone failure pause the game with retry/touch-practice choices. Touches cannot impersonate sound while microphone mode is active, and direct action-button input can no longer bypass pattern matching.

The microphone uses an Animal Choir-specific sound-gate profile with faster release. Pattern parsing confirms a brief quiet interval before ending a call, so small dropouts do not split a woof into two while real gaps still separate successive calls. Tiny spikes are ignored; wrong call durations, excess calls and timeouts provide specific feedback. Sound durations use real time while later-stage cue deadlines accelerate.

The game shows short/long beat markers, current call count and MIC ON or TOUCH PRACTICE status. The highlighted animal reacts during a call. Hear pattern plays an original synthetic cartoon example for the current animal; it pauses the round and stops microphone capture before playback. After the example and a short speaker tail, microphone mode recalibrates before the attempt resumes. The example cannot score coins. Replaying a guide resets the partial attempt without losing a life. User pause, changing games and backgrounding cancel guide playback and prevent stale callbacks from resuming a different round. Camera settings, face calibration changes and game-area dimensions are preserved.

Validation: 30 synthetic PCM animal cues completed all five stages. Checks covered calibration freeze, correct call durations/counts, brief-dropout tolerance, demo freeze, partial-attempt reset, scoring-shortcut rejection and corrective feedback. Existing 75-stage winning paths, 15-game winning/losing paths, 70 touch-compatible stage paths, stage-speed checks, Firefly PCM wins and Sound Grand Prix PCM wins passed. Offline debug/test build and Android lint passed. Native tests verified independent sound settings, 12 animal calibration/rhythm/touch scenes and Hear pattern hit targets. The rhythm-progress scene was visually reviewed. Native checks did not open the microphone or play speaker audio. Real microphone and guide-playback experience still needs a live user test.
